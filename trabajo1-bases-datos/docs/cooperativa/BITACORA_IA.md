# Bitácora de uso de Inteligencia Artificial

## 1. Información general

- **Proyecto:** Trabajo 1 – Bases de Datos
- **Módulo:** Sistema de Cooperativa de Ahorro y Crédito
- **Responsable:** Quinchiguango Jared
- **Herramienta utilizada:** ChatGPT (OpenAI)

## 2. Descripción del uso de IA

Durante el desarrollo del proyecto se utilizó ChatGPT como herramienta de apoyo para organizar las actividades, comprender mejor los requerimientos del ejercicio y definir una estructura adecuada para el proyecto.

También se empleó para consultar dudas técnicas, revisar errores encontrados durante la programación y obtener sugerencias para implementar y comprobar algunas funcionalidades.

Las respuestas y propuestas proporcionadas por la herramienta fueron revisadas y verificadas mediante la ejecución del programa.

## 3. Registro de uso y verificación

| Actividad | Uso de IA | Verificación realizada |
|---|---|---|
| Análisis de requerimientos | Apoyo para comprender las reglas del ejercicio. | Revisión de los requisitos establecidos en el documento del taller. |
| Organización del proyecto | Orientación para estructurar las clases y paquetes Java. | Revisión de la estructura y compilación del proyecto. |
| Resolución de errores | Consulta de posibles soluciones a problemas técnicos. | Aplicación de las correcciones y nuevas ejecuciones del programa. |
| Apoyo en implementación y pruebas | Consulta de ejemplos y sugerencias de código. | Ejecución de operaciones, pruebas automatizadas con JUnit y comprobación de resultados. |

## 4. Verificación de resultados

Para comprobar el funcionamiento de las soluciones utilizadas, se realizaron compilaciones mediante Maven, pruebas funcionales del sistema y pruebas automatizadas con JUnit.

También se verificó el almacenamiento y la recuperación de información mediante archivos JSON.

## 5. Declaración final

Se declara el uso de ChatGPT como herramienta de apoyo académico durante el desarrollo del módulo de Cooperativa de Ahorro y Crédito, principalmente para la organización del trabajo, comprensión de requerimientos, resolución de dudas y revisión de aspectos técnicos.

Las sugerencias utilizadas fueron comprobadas mediante compilaciones, ejecución del sistema y pruebas automatizadas.

Esta declaración se presenta en cumplimiento del compromiso 7 del sílabo de la asignatura, relacionado con el uso declarado y verificado de herramientas de inteligencia artificial.
